# Metod-Nyton
# Документация к программе решения нелинейного уравнения

## 1. Описание программы

### 1.1. Назначение

Программа представляет собой консольное приложение на языке **Java**, предназначенное для приближённого решения нелинейного уравнения вида

\[
f(x) = 0
\]

двумя классическими численными методами:

- **методом Ньютона** (метод касательных);
- **методом Хорд** (метод секущих).

В качестве конкретного уравнения используется функция:

\[
f(x) = 2x - \frac{1}{\tan(x)}
\]

Корень уравнения ищется на отрезке \([a; b]\), по умолчанию \([0{,}1;\ 1]\), с точностью \(\varepsilon = 0{,}0001\).

> ⚠️ Точка \(x = 0\) исключена из рассмотрения, так как функция \(f(x) = 2x - 1/\tan(x)\) в ней не определена (\(\tan(0) = 0\), деление на ноль).

---

### 1.2. Основные возможности

Программа позволяет:

1. **Задавать входные параметры** через консоль:
   - левую границу отрезка \(a\);
   - правую границу отрезка \(b\);
   - точность вычислений \(\varepsilon\);
   - начальное приближение \(x_0\) для метода Ньютона;
   - максимальное количество итераций \(n\).

2. **Использовать значения по умолчанию**, если пользователь просто нажмёт Enter:
   - \(a = 0{,}1\);
   - \(b = 1{,}0\);
   - \(\varepsilon = 0{,}0001\);
   - \(x_0 = 0{,}5\);
   - \(n = 100\).

3. **Проверять корректность отрезка** — программа предупреждает, если на концах отрезка функция не меняет знак (тогда корня на этом отрезке может не быть).

4. **Выводить пошаговую таблицу итераций** для каждого метода:
   - номер итерации;
   - текущее приближение;
   - значение функции в этой точке;
   - разность между соседними приближениями (или длину текущего отрезка для метода Хорд).

5. **Автоматически останавливать вычисления**, когда:
   - достигнута заданная точность \(\varepsilon\);
   - или исчерпано максимальное число итераций.

6. **Выводить итоговый результат**:
   - найденный приближённый корень;
   - значение функции в этой точке (контроль, что оно близко к нулю);
   - количество выполненных итераций.

---

### 1.3. Структура программы

Программа состоит из четырёх основных частей:

| Часть | Назначение |
|---|---|
| `f(x)` | Вычисление значения функции \(f(x) = 2x - 1/\tan(x)\) |
| `df(x)` | Вычисление производной \(f'(x) = 2 + 1/\sin^2(x)\) |
| `newton(x0, eps, maxIter)` | Реализация метода Ньютона |
| `chord(a, b, eps, maxIter)` | Реализация метода Хорд |
| `main()` | Ввод данных, проверка отрезка, запуск методов |

---

### 1.4. Ограничения и особенности

- Функция \(f(x)\) не определена в точке \(x = 0\), поэтому левая граница отрезка должна быть **строго больше нуля**.
- **Метод Ньютона** требует удачного выбора начального приближения \(x_0\): если \(x_0\) слишком далеко от корня, метод может разойтись или «уйти» за пределы области определения.
- **Метод Хорд** требует, чтобы на концах отрезка функция имела **разные знаки**: \(f(a) \cdot f(b) < 0\).
- Если \(\tan(x)\) близок к нулю, функция резко возрастает по модулю — это может приводить к большим промежуточным значениям.
- Точность \(\varepsilon\) задаётся как модуль разности двух соседних приближений (для Ньютона) или как длина текущего отрезка (для Хорд).

---

### 1.5. Пример работы

При значениях по умолчанию:

```
Решение уравнения: f(x) = 2x - 1/tan(x) = 0
Отрезок по умолчанию: [0.1; 1]  (в точке 0 функция не определена)

=== Метод Ньютона ===
Итер   x               f(x)            |x - x_prev|    
1      0.72289925      -0.03886069     0.22289925     
2      0.70213439      -0.00107625     0.02076486     
3      0.70152380      -0.00000103     0.00061059     
4      0.70152320      -0.00000000     0.00000060     
Достигнута заданная точность.
Найденный корень: x = 0.70152320
Значение f(x) = -0.00000000
Количество итераций: 4

=== Метод Хорд ===
...
Найденный корень: x = 0.70152321
Значение f(x) = -0.00000000
Количество итераций: 18
```

**Итог:** оба метода дают один и тот же корень \(x \approx 0{,}7015\), но метод Ньютона сходится за 4 итерации, а метод Хорд — за 18.

## 2. Описание алгоритмов

### 2.1. Метод Ньютона (метод касательных)

#### Идея метода

На каждой итерации функция \(f(x)\) заменяется касательной, проведённой в текущей точке \(x_k\). Точка пересечения этой касательной с осью \(OX\) берётся как следующее приближение \(x_{k+1}\).

#### Формула

\[
x_{k+1} = x_k - \frac{f(x_k)}{f'(x_k)}
\]

#### Пошаговый алгоритм

1. Ввести начальное приближение \(x_0\), точность \(\varepsilon\), максимум итераций \(n\).
2. Положить \(k = 0\), \(x = x_0\).
3. Вычислить \(f(x)\) и \(f'(x)\).
4. Если \(|f'(x)| < \delta\) (очень мало) — прервать с сообщением об ошибке.
5. Вычислить \(x_{\text{new}} = x - f(x)/f'(x)\).
6. Если \(|x_{\text{new}} - x| < \varepsilon\) — корень найден, перейти к шагу 9.
7. Иначе \(x = x_{\text{new}}\), \(k = k + 1\).
8. Если \(k < n\) — вернуться к шагу 3; иначе — вывести сообщение, что точность не достигнута.
9. Вывести \(x_{\text{new}}\) как приближённый корень.

#### Блок-схема (текстовая)

```
    ┌─────────────────────┐
    │ Ввод x0, ε, n       │
    └──────────┬──────────┘
               ▼
    ┌─────────────────────┐
    │ k = 0, x = x0       │
    └──────────┬──────────┘
               ▼
    ┌─────────────────────┐
    │ Вычислить f(x), f'(x)│
    └──────────┬──────────┘
               ▼
    ┌─────────────────────┐
    │ x_new = x - f/f'    │
    └──────────┬──────────┘
               ▼
    ┌─────────────────────┐
    │ |x_new - x| < ε ?   │─── да ──► Вывод корня x_new
    └──────────┬──────────┘
               │ нет
               ▼
    ┌─────────────────────┐
    │ x = x_new, k = k + 1│
    └──────────┬──────────┘
               ▼
    ┌─────────────────────┐
    │ k < n ?             │─── да ──► (наверх к вычислению f)
    └──────────┬──────────┘
               │ нет
               ▼
    ┌─────────────────────┐
    │ Вывод: не сошлось   │
    └─────────────────────┘
```

---

### 2.2. Метод Хорд (метод секущих)

#### Идея метода

На каждой итерации через две точки графика функции проводится хорда. Точка пересечения хорды с осью \(OX\) берётся как новое приближение. Затем выбирается тот отрезок (левая или правая половина), на концах которого функция меняет знак.

#### Формула

\[
x = a - f(a) \cdot \frac{b - a}{f(b) - f(a)}
\]

#### Пошаговый алгоритм

1. Ввести границы \(a\), \(b\), точность \(\varepsilon\), максимум итераций \(n\).
2. Вычислить \(f(a)\), \(f(b)\).
3. Проверить: \(f(a) \cdot f(b) < 0\). Если нет — сообщить, что на отрезке нет корня (или предупредить).
4. Положить \(k = 0\).
5. Вычислить \(x = a - f(a) \cdot (b - a)/(f(b) - f(a))\).
6. Вычислить \(f(x)\).
7. Если \(|b - a| < \varepsilon\) или \(|f(x)| < \varepsilon\) — корень найден, перейти к шагу 10.
8. Выбрать новый отрезок:
   - если \(f(a) \cdot f(x) < 0\), то \(b = x\), \(f(b) = f(x)\);
   - иначе \(a = x\), \(f(a) = f(x)\).
9. \(k = k + 1\); если \(k < n\) — вернуться к шагу 5; иначе — вывести сообщение, что точность не достигнута.
10. Вывести \(x\) как приближённый корень.

#### Блок-схема (текстовая)

```
    ┌─────────────────────┐
    │ Ввод a, b, ε, n     │
    └──────────┬──────────┘
               ▼
    ┌─────────────────────┐
    │ fa = f(a), fb = f(b)│
    └──────────┬──────────┘
               ▼
    ┌─────────────────────┐
    │ fa * fb < 0 ?       │─── нет ──► Ошибка: нет корня
    └──────────┬──────────┘
               │ да
               ▼
    ┌─────────────────────┐
    │ k = 0               │
    └──────────┬──────────┘
               ▼
    ┌─────────────────────┐
    │ x = a - fa*(b-a)/   │
    │        (fb - fa)    │
    └──────────┬──────────┘
               ▼
    ┌─────────────────────┐
    │ fx = f(x)           │
    └──────────┬──────────┘
               ▼
    ┌─────────────────────┐
    │ |b-a| < ε или       │─── да ──► Вывод корня x
    │ |fx| < ε ?          │
    └──────────┬──────────┘
               │ нет
               ▼
    ┌─────────────────────┐
    │ fa * fx < 0 ?       │
    └────┬───────────┬────┘
        да           нет
        ▼            ▼
   b = x, fb = fx  a = x, fa = fx
        └─────┬──────┘
              ▼
    ┌─────────────────────┐
    │ k = k + 1           │
    └──────────┬──────────┘
               ▼
    ┌─────────────────────┐
    │ k < n ?             │─── да ──► (наверх к вычислению x)
    └──────────┬──────────┘
               │ нет
               ▼
    ┌─────────────────────┐
    │ Вывод: не сошлось   │
    └─────────────────────┘
```

### 2.3. Сравнение методов

| Критерий | Метод Ньютона | Метод Хорд |
|---|---|---|
| **Скорость сходимости** | Квадратичная (очень быстрая) | Линейная (медленнее) |
| **Нужна производная** | Да | Нет |
| **Входные данные** | Одно начальное приближение \(x_0\) | Отрезок \([a; b]\) |
| **Условие сходимости** | Удачный выбор \(x_0\) | Смена знака: \(f(a) \cdot f(b) < 0\) |
| **Число итераций (пример)** | ~4 | ~18 |
| **Устойчивость** | Чувствителен к выбору \(x_0\) | Более устойчив |
| **Простота реализации** | Проще | Чуть сложнее |

Оба метода дают один и тот же корень \(x \approx 0{,}7015\) с точностью \(\varepsilon = 0{,}0001\), но метод Ньютона сходится значительно быстрее за счёт использования производной.
